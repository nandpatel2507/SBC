RESTAURANT DISCOUNT FINDER - DEPLOYMENT GUIDE
=============================================

FILES TO UPLOAD TO GITHUB:
1. app.py (main application file)
2. requirements.txt (dependencies)
3. README.md (documentation)
4. .gitignore (ignore unnecessary files)
5. config.toml (Streamlit configuration)
6. SETUP_GUIDE.txt (this file)

STEP-BY-STEP DEPLOYMENT:

1. CREATE GITHUB REPOSITORY
   - Go to github.com
   - Click "New Repository"
   - Name it (e.g., "restaurant-discount-finder")
   - Make it Public
   - Don't initialize with README (we have our own)
   - Click "Create repository"

2. UPLOAD FILES TO GITHUB
   - Click "uploading an existing file"
   - Drag and drop all files OR click "choose your files"
   - Select all 6 files
   - Add commit message: "Initial commit - Restaurant Discount Finder"
   - Click "Commit changes"

3. DEPLOY ON STREAMLIT CLOUD
   - Go to share.streamlit.io
   - Sign in with GitHub
   - Click "New app"
   - Select your repository
   - Branch: main (or master)
   - Main file path: app.py
   - Click "Deploy"
   - Wait 2-3 minutes for deployment

4. GET ANTHROPIC API KEY
   - Visit console.anthropic.com
   - Sign up or log in
   - Go to API Keys section
   - Click "Create Key"
   - Copy the key
   - Paste it in the app sidebar when you use it

5. USE THE APP
   - Once deployed, Streamlit will give you a URL
   - Open the URL
   - Enter your API key in the sidebar
   - Set your location
   - Start searching for restaurant deals!

TROUBLESHOOTING:

- If deployment fails: Check that app.py is in the root directory
- If imports fail: Verify requirements.txt is correct
- If API errors: Make sure your Anthropic API key is valid
- If search doesn't work: Check your API key has credits

CUSTOMIZATION:

- To change colors: Edit config.toml
- To add features: Edit app.py
- To add dependencies: Add to requirements.txt

SUPPORT:

- Streamlit Docs: docs.streamlit.io
- Anthropic Docs: docs.anthropic.com
- GitHub Docs: docs.github.com

IMPORTANT NOTES:

- Keep your API key private - never commit it to GitHub
- The app doesn't store your API key
- Web search requires active Anthropic API subscription
- Free tier has usage limits
